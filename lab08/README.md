### Задание 1 **(2)**

_Рассмотрим программу на языке_ **Python**.

```

   if x[i] < i or x[i] > 2*i:

```

_Перепишите эту программу так, чтобы в ней использовался цикл_ **while**, _в ней не использовалась

вид._

```
x = [int(t) for t in input().split()]
i = 0
while ...:
   i += 1
print(i)
```

_Допишите правильное логическое выражение вместо многоточия. Выражение не должно содержать оператор_ **not**.

**Ответ:**

```

**Ответ:**

```

    public static void main(String[] args) {
        int[] zero = new int[2];
        int[][] vec2 = {
                { 1, 2, 3 },
                { 4, 0, 1 },
                { 2, 3, 4 }
        };
        flag: for (int i = 0; i < vec2.length; i++) {
            for (int j = 0; j < vec2[i].length; j++) {
